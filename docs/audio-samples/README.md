# Block Blast 现成采样试听库 · 2026-10-24

地址：[独立采样试听库](https://zslhentai.github.io/block-blast-web/audio-lab/samples.html)。

本轮改为现成音效采样路线，仅做选段、均衡、淡入淡出和共同试听增益。**没有制作新的振荡器音色、噪声、脉冲响应或程序化 PCM 音效；没有叠层、变调、时间伸缩或动态混音。** WAV 是已有素材的转码/剪辑结果，不是从零生成的声音。

## 完成程度与听审边界

取得并初筛 12 个素材，每类 3 个供用户选择。已核验许可、来源字节、波形、电平和浏览器播放；**当前工具不能可靠听辨音色，本轮没有人工听审，也没有认定这些素材已接近原版或已达到“高品质成品”验收。** 页首和每项说明均保留待听审状态，没有把 playing 事件、频谱或数量当作听感保证。

Kenney 素材是现成音效/短奖励句，官方没有逐项说明其录制或制作方法，因此不一概称为现场录音。VCSL 则按其项目说明属于实录乐器采样。声音风格有差异，若全都不合适，应整批排除，不因为已经制作网页就强行接入。

筛选仍参考原录屏研究：普通落子后的确认音较短、明亮；单行消除是较快起音与衰减；多行/Combo 在片中重叠，无法精确拆分。本批将轻碰、实录钟铃/音树、颗粒扫奏及现成奖励句分别列出，只是可比较的材质方向，没有宣称还原原版源音轨。

## A/B 的含义与处理

- **完整原文件**：`original/` 中保存从所列来源取得的字节，不改写格式/内容，保留原始电平，可听或下载。部分录音原电平很轻，部分 OGG 解码浮点峰值会超过 1；应先降低设备媒体音量。旧 Safari 对完整 OGG 格式的支持可能不同，失败时仍可听兼容的 WAV 选段或下载原文件。
- **A 原声选段**：解码为 48 kHz 双声道 PCM16 WAV，取元数据中列明的片段，使用共同试听增益，并做 5 ms 结尾防爆音收尾（含重采样后的端点归零）；不做均衡、变调或叠层。**A 不是“原文件逐字节不变”**，完整原文件另行提供。
- **B 加工版**：从同一起点取更适合事件的长度，做低幅度高低通清理、必要的 3.6 kHz 轻削减、2 ms 淡入及 25–160 ms 淡出。VCSL/现成奖励句保留较宽频段，没有统一削去亮部。每个确切参数均显示在卡片与目录中。
- **共同增益**：每对 A/B 使用相同增益，使两版中较高峰值为 0.33，避免以更响的 B 假装音色改善。并非逐个样本都施加相同 dB；也不是 LUFS 或人耳响度严格匹配。某些原始乐器录音需约 +32/+34 dB 配平，页面逐项显示，不掩饰原始电平差异。
- 解码后先将时间戳归零再截取，避免部分 OGG 的负起始时间戳导致短起音丢失；原始文件字节不变。
- 不重新配旋律，不加新的振荡器、噪声、混响或人为颗粒，不叠加第二个素材。这里的“风铃颗粒”来自录音本身。

A/B 使用相同播放器，支持单独点击 A/B、A→B 或 B→A。自动对比在两段之间留 0.4 秒；新点击、换分类、停止、隐藏/离开页面都会取消上一组。iPhone 仍以音量键调节媒体音量；未设置不可靠的 iOS 软件音量滑杆。若自动续播被 Safari 限制，直接点击下一版即可，页面会显示提示。

## 保留范围

正式游戏源码、音效模块、规则、计分、存档、输入、动画和静态布局未改。V1、V2 音效实验室实现保留，只在其页面添加通往采样试听库的链接。新页面仅用原生 HTMLAudioElement 播放已经存在的文件，不需要 AudioContext，也不读取/写入游戏存档。

## 复现与审计

`scripts/sample-recipes.json` 记录来源固定提交、文件路径/字节数、Git blob、选段与处理参数；`scripts/prepare-sample-library.py` 从已提交原文件重新生成 A/B 和目录，不访问网络。该离线编辑脚本需要 FFmpeg；项目正常构建、网页运行和 CI 单元检查不需要新增 Python/FFmpeg 依赖。

```sh
python3 scripts/prepare-sample-library.py
```

这里的 Python/PCM 转码只是处理现有录音，不是延续 V2 的从零程序化音色生成器。
