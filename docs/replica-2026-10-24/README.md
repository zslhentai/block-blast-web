## 不确定性与边界

原版隐藏发牌概率、确切计分及完整连击规则未证实。Android 复刻源码是独立实现，不能用来证明商业原版。静态截图不能证明动画时长；录屏有部分音频叠加，当前工具不能可靠人工听辨。上述部分采用可解释替代或保留待真机/用户判断，不宣称像素级、听感或隐藏算法还原。

没有可合法分析的 Cocos 构建容器/脚本对象，因此 REA / cc-reverse 不运行、不安装、不解密。已安装的云端/执行器 Skill 清单中无 Ponytail、Grill Me。Game Feel 仅采用事件分级、短缓动、反馈不阻塞规则等原则，无 Godot 代码迁入。

## A：规则复核结果

两项确认差异已修复：

1. IMG_8323 的中间蓝色和右侧黄色均为横向三格，IMG_8326 的橙色与青色均为竖向两格，证明原版允许同形手牌。现在三个槽独立加权取样，几何可重复，ID 始终独立；没有新增形状。
2. 发牌改为 `independent-weighted-v2`：保持既有体积/家族权重与渐进曲线，取消棋盘求解重抽和可放修复。新组也可能直接终局，不暗中更换已展示手牌。`findSequence` 仅供离线审计，生产发牌不调用。

8×8、39 朝向、两种斜对角空白不碰撞、整组补牌、同时行列并集、计分/Combo、终局、存档均继续使用已有模块。原版确切分数和隐藏概率未证实，不改原有可解释计分。存档版本/原手牌/RNG/最高分不重置；恢复后未来新手牌采用新策略。

## B/C：操作与反馈

- 保持 V1.1 的 `drawPreview`，无新增描边、强光或替代高亮。CSS 坐标、1.15 格手指补偿和释放事件坐标继续权威；不引入插值延迟或额外吸附。画布位置变化/visualViewport 滚动时取消当前拖拽，避免重排竞态错落。
- 同一提交/形状/锚点的合法性与消线预览缓存复用，手指浮动位置仍每帧直接跟随最新事件，不缓存或延后输入坐标。
- 放置回弹 145 ms，最大放大 5.5%，前段快速响应后缓出回位；普通消除 70 ms 短保持、330 ms 内收束、420 ms 粒子结束。Combo 攻击 140 ms、总长 700 ms。均为可调的合理起点，不冒称原版时长。
- `FEEDBACK_STRENGTH` 集中普通/强化/奖励三级参数。单线为普通，多线或 Combo 2 强化，三线及以上或 Combo 3+ 奖励；对应粒子目标 8/14/20，受清除格数与全局 48 粒子限制。多线仍是一个并集事件，交叉格只绘一次。降低填白覆盖，保留原有方块颜色和倒角，金色高阶文字的光色保持一致。
- 每格最近反馈提交记录在固定 64 项表中；新放置或再次消除立即取得所有权。即使最终该格又为空，旧快照也不能覆盖新消除颜色；旧粒子源及落在新实体格上的粒子会跳过。最多三次反馈，无动画输入锁，无计时器提交规则。
- 静态 `draw.ts`、`theme.ts`、`canvas.ts`、`src/style.css` 未改；既有棋盘缓存继续复用，没有重复实现一套材质。

验证：24 项渲染单元测试及 42 项反馈/交互 Chromium E2E 通过。真实 CDP 触控逐一放置全部 39 朝向，横跨 320×568、393×852、412×915；验证连续行→列重叠消除、CSS 位置改变、视口滚动取消、同格预览缓存，以及原暂停/后台/取消/减少动画回归。CDP 属模拟触控，不是手机真机。

## D：场景音效 A/B 与调度

[打开真实棋局场景试听](https://zslhentai.github.io/block-blast-web/audio-lab/scenes.html)。A 为现有音效，B 仅以已核验 CC0 的 P2（Kenney 木质轻碰）/R1（Dustyroom 短和弦）分别试听放置/单行。P2 只是用户暂留，R1 尚未认可；没有增加第三版合成方案，没有替换正式默认音色。多线和 Combo 虽有独立类型，目前仍回退现有 clear 声；素材和听感部分保留待用户选择，不声称声音专项已经还原。

场景页复用正式页面的同一 renderer/reducer/输入，提供空盘、单行、双行、双列、交叉、Combo 2/3 固定棋局，A/B 切换或重置后起点一致。通过显式 `audioLab=1` 门控启用；只传 `profile` 不会改变正式游戏。场景完全不读写正式 localStorage、sessionStorage 游戏身份/设置，页面明确说明不保存。切换后将游戏框滚到可视区，不需强制点击画面外按钮。

一次已提交的 `MoveFeedback` 决定放置/单行/多线/Combo，带 revision 和与视觉时间线相同的 `startAt`。实际调度在当前 AudioContext 时刻开始，没有页面延迟猜测、解码后补播、动画结束后再计分。读取最近 16 次事件的只读诊断可核对触发次数/类型/起点/实际调度与回退；它不是扬声器实测延迟。

采样解码缓存最多两个 WAV，最多三个活动声部及一个 8 ms 退场声部，新起音压低旧尾音。切换到旧声回退时停止采样，切换到采样时停止旧声，避免两套图同时累加。文件数字峰值≤0.331、增益≤0.08、最多四个采样源的保守峰值和≤0.106；这不代表主观响度匹配或手机声压验收。没有新增混响、变调、合成素材或第三方音频服务。

首次手势创建/恢复 AudioContext，再开始异步解码；加载未完成、404 或格式失败时，当次事件立即回退旧声。加载完成只更新缓存，不追播刚才的声音。重置/重载可重试失败资源。暂停、静音、隐藏或离开停止活动及退场声部；修复旧 SoundManager 的异步 resume 在暂停之后才完成而意外恢复上下文的问题。

验证：严格类型、全量 124 单元测试、9 项场景 Chromium E2E 通过。浏览器实际 BufferSource/Oscillator 启动次数与事件数一致，视觉/音频请求时间戳相同；验证七场景双配置、缺失资源回退和重试、取消/静音/后台无旧事件补播、嵌入框真实 CDP 触控及正式存档 sentinel 不变。当前没有真实 Safari 音频解锁或手机听辨证据。

原录屏本轮仍可读取：55.783 秒 HEVC / AAC 44.1 kHz 双声道，SHA-256 `54091cd78a5288785db7726154cac90e9b05424f2544035e43f5627503e49422`。FFmpeg 重新解码与前次 PCM 一致；复核 4.95–5.10 / 6.19–6.34 秒放置、18.70–19.71 秒单线及 25.22 / 27.12 秒连击窗口。约 150 ms 放置与消除主音组只是测量描述，混合的多线/Combo 不能拆成独立原声。沿用[录屏事件与音轨报告](../audio-study-2026-10-24/report.md)、[采样对照及许可](../audio-samples/README.md)，不把无法人工听辨的工具输出写成主观音色判断；没有公开该商业音轨或其裁切片段。

Playwright 用固定存档 fixture 和虚拟时钟捕捉空盘/中盘/拖拽/消除/Combo/终局；没有新增可任意改写正式游戏状态的全局调试入口。真实时钟压力测试另行记录绘制耗时、长任务、四个回收后堆内存点、画布创建量和空闲后 rAF 停止，不能把虚拟时钟截图用作 FPS 证据。

后续必须保留：V1.1 静态方向、无浅色落点外框、独立且不强保解的发牌、现有 MIT/来源/存档、音效素材审批状态。不要把本轮合理替代方案升级成“原版已证实”；P2 暂留、R1 待选、其余旧候选已淘汰，不应重新推荐淘汰项或强行接入。声音材质、手机扬声器音量、真实手指补偿、Safari 地址栏/安全区和长时间手机耐久仍需真机判断，其他客观开发不因这些事项停工。
