## 关键回归

- pointercancel 不再落子，不扣手牌、不加分；第二触点不能接管活动拖拽。
- 越界/重叠、空槽、外来或已消费 shapeId、旧版本事件、暂停/结束状态均不能提交。
- 最后一块落定先统一消除，再发新手牌，然后判负；没有“空手牌即死”。
- 一行一列交叉消除：15 个去重格、2 线、首次 +181；三行三列：39 格、6 线、3×3 放置首次 +609。
- 窗口变化不仅依赖 ResizeObserver，还在 pointerup 比较 CSS 尺寸/视口/DPR，覆盖快速旋转与立即松手的竞态。
- 刷新恢复 board/shapes/score/highScore/combo/dryMoves/round/RNG/settings；暂停不会断连。当前文档与前一文档使用稳定写入标识，避免刷新时旧 storage 事件误判成另一标签编辑。
- 页面启动标志、只读状态、实际落子/得分/消除/换组/结束和存储结果都进入 E2E；脚本加载失败不可能仅靠 Canvas 存在通过验收。

## 检查命令与证据

使用项目 README 中的类型检查、单测、E2E、脚本缺失守卫和构建命令。最终实测结果见同目录 `MVP-validation.json`；正常浏览器报告生成在 `playwright-report/`，仅保留本地不进 Git。

`test:e2e:guard` 是预期失败验证：阻断生产 JS 后，正常正向启动测试必须因 `GAME_SCRIPT_NOT_READY` 失败（退出 1）；守卫本身检查这一结果后返回 0。它不禁用断言、不添加无条件 skip，也不把“零个测试执行”当成功。

初版单元测试包括 100 个空盘发牌见证重放、1,000 组手牌去重以及 30 个 seed 的最多 100 步合法棋局/确定性回放；这些不等于研究报告中计划的发布级 10,000 seed 平衡与长局验收。

当前生成的 `artifacts/block-blast-mvp.html` 是可下载的自包含试玩页；该文件由同一 `src/index.ts` 打包，不是另写的演示。生产 `dist/` 可以部署至 Pages 子路径，CI 内置检查该路径。本轮没有宣称公网地址已发布；云内部端口不自动对外可见。详见 README 的实际启动与部署步骤。

提交按研究、原始上游导入、MVP 功能/回归和交付记录分开保留。`git log --oneline` 查看精确记录。回退功能优先 `git revert <功能提交>`，保留后续文档和审计历史；需要查看原始上游可检出导入提交。不要对已有用户改动运行破坏性的 hard reset。

## 未验证及剩余风险

- 浏览器 E2E 的 iPhone/Pixel 名称表示 Chromium 设备模拟，不表示真机或 Safari。当前无安装好的 WebKit，也没有实体手机。
- 未做真实设备的 30 分钟长局、音频听感、低端帧率、电量、刘海/灵动岛及安装到主屏验证。
- 尚未实施 Service Worker 缓存/升级和正式 PWA 安装；已验证单文件 HTTP 载入后断网游玩，站点离线刷新不保证。托管浏览器禁止 `file:`，本环境不能直接验证下载文件打开。
- 本地存储受浏览器隐私模式、配额和用户清理控制；无跨设备同步。复制标签页等共享 sessionStorage 的并发情况待进一步测试。
- 发牌的完整有解优先和保底修复是本项目规则；超预算不保证整组三块可解。完整难度分布与家庭试玩平衡仍待后续。
- GitHub Pages 工作流已准备，但本地代码提交、远端推送、Actions 执行与实际网站发布是不同结果，不能互相替代。
