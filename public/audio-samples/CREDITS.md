## 原文件、电平与试听边界

完整原文件未改动，部分录音本身电平很轻，部分有损压缩文件解码后可能出现超过 1 的峰值；请从低媒体音量开始。A/B WAV 选段使用同一组共同增益，数字峰值不超过 0.33，不用更响的 B 代替音色改善。配平不是 LUFS 或主观响度严格一致。

本页面使用原生 HTML 音频播放器，不使用 Web Audio 合成或 V2 程序化 PCM 音色。音频输出为 WAV 只是将已有录音转码/剪辑，不是从零合成。没有改调、时间伸缩、新增噪声、混响或叠层。

CC0 允许改编和分发；来源保留为审计用途，不意味着官方背书。具体许可全文见 licenses/。

本目录新增的试听选段和加工版本也按 CC0-1.0 提供；网页代码沿用项目代码许可证。

## 第二轮：录屏定向候选 R1

R1 为 Dustyroom 的 `DM-CGS-12.wav`，来自 [Free Casual Game Sounds](https://dustyroom.com/free-casual-game-sounds/)，官方声明 CC0。经 [固定公开副本](https://github.com/YagmurCemGul/my-awesome-game/blob/bff6e4b702a0e13182f8adaf89572814e147dbc4/Assets/CasualGameSounds/DM-CGS-12.wav) 取得，原文件与该提交 Git blob `2950b4cd61a254eaec52af263fa8e1065a931431` 一致；未与官网 ZIP 逐字节对照。

来源包的许可说明原件保存在 [dustyroom-source.pdf](./licenses/dustyroom-source.pdf)，对应 Git blob `23ccf2eb93b648284c13ec64ef1c3d55154874f9`。CC0 全文另存 [dustyroom-CC0.txt](./licenses/dustyroom-CC0.txt)。作者说明其素材结合录制、合成与处理，不将其称为全部现场实录；本项目仅剪辑现有文件，没有从零合成。

R1 对照用户录屏 18.70–19.71 秒的单行消除，按主音组与衰减筛选；指标不是听感相似度。本次没有公开用户录屏或其中的原版商业声音。A 为 0–1.800 秒原声选段；B 为 0–1.020 秒，30 Hz 高通、18 kHz 低通、2 ms 淡入、60 ms 淡出，无转调/叠层；共同增益和哈希见 catalog.json。
