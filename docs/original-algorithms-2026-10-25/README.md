## 实施与验收约束

1. 先保存旧版固定种子数据；搜索正确性、见证重放及 unknown 边界通过后再做候选发牌。
2. 按节点/工作量限制运行，不能以设备快慢改变随机结果；耗时只作诊断。
3. 独立难度配置须与随机和单步启发式玩家对照，记录截断局、得分、局长、死因、连消、发牌成本及重复度；不是人类体验实测。
4. 新手帮助与挑战都有限，普通随机仍可无解；不保证每一轮可放完，不主动寻求必败组合。
5. 严格类型、单元、完整 E2E、构建及便携版回归；算法诊断仅开发环境显式开启，不进入普通玩家 UI。
6. 仅推送研究分支触发验证和便携预览附件；不向 main/work 合并，不触发线上 Pages 发布。

## 搜索检查点

独立实现 `board-search.ts`：两枚无符号 32 位占用字、固定形状落点缓存、剩余槽位掩码与棋盘联合去重；每落一块立即清行列，遍历不同槽位顺序。只读取输入，重复几何仍按不同槽位计路径。统计 `solutions` 仅在 `exhaustive=true` 时是精确值，否则是已证下界；零解且预算不足只能返回 unknown。预算按候选落点检查次数确定，设备耗时不改变搜索结论或 RNG。

6 项新增单测 + 4 项原发牌测试通过。32 组固定随机棋盘×全部 39 朝向的每个几何落点，与现有生产碰撞及消除函数交叉核对；含高位边界、斜对角空白、行列交叉。输入冻结验证无修改；测试分别覆盖满盘、无解、低预算 unknown、空槽、重复形状及必须先消两行才能放第三块。

无需原版代码即可独立算出空盘上竖骨牌、横骨牌、3×3 方块的每个顺序 67,680 条路径，六顺序合计 406,080。与文章公布的空盘数字一致，但不代表已经取得或验证其 171 个落点的死局棋盘。`lethal-study.ts` 只是研究分类器，生产发牌不导入它。

基线重新运行 124 单元通过；旧版 20,000 局固定种子原始结果见 [legacy-simulation.json](legacy-simulation.json)。新的同规则得分/连击/风险指标比较将由同一模拟程序同时测量基线和候选，避免混用不同自动玩家统计。

## 独立发牌设计

`bounded-classic-v3` 不是原版算法复刻声明。依照本轮新授权，在上一轮随机基线上增加条件候选选择；不恢复早期 12 次重抽/求解保解修复。

```text
既有家族/体积加权 → 四组候选 + 策略随机数（固定 13 次 RNG）
  ├─ 普通：保留第一组，允许自然无解
  ├─ 帮助：有限候选中，选择已证可解且空间/连通性/消线指标较好的组
  └─ 挑战：仅在较宽裕且已有连消时，从已证可解候选中选较有约束的组
候选不足/搜索 unknown：保留原第一组，不修复、不追加搜索、不假称有解
```

搜索每候选最多 2,000 次落点检查，最多四候选，总工作量≤8,000；普通组审计最多 512。最多收集八条成功路径，达到上限后的数量是下界；某些空间/消线指标来自有限首路径样本，具有顺序偏差，不是原版隐藏难度、最优未来或概率估计。空间、孤格、相邻空格、当前合法锚点、路径数量下界、消线与近期家族多样性共同参与独立排序，没有只按“可解/不可解”一刀切。

| 参数 | 平衡候选值 / 约束 |
| --- | --- |
| 基础帮助概率 | 0.28；前 3 组 +0.20；拥挤/孤格/低空间干手时 +0.25，最高 0.80 |
| 基础挑战概率 | 0.12；仅第 8 组后、至少 24 空格且 combo≥2，其他时候为零 |
| 连续策略保护 | 最多连续两组帮助、最多一组主动挑战；达到上限后禁用对应策略一次 |
| 多样性 | 近期六个家族参与软惩罚，同形和同家族仍可出现；不改变方块池 |
| 明确排除 | 不读最高分、广告、收入、地区、机型、操作速度；不运行必败题生成器 |

这些概率是本项目初始候选值，经下面的多参数与留出测试保留，不称为恢复了原版默认分布。“连续策略保护”限制的是本项目主动选择的策略类别，不保证普通随机组的客观难度不会连续偏高，也不保证玩家永远有解。

### 模块与兼容

- `board-search.ts`：占用搜索，颜色与计分仍在生产规则中。
- `adaptive-dealer.ts`：纯候选/策略/评估；`randomHand` 原样保留 v2 控制组的三次 RNG 与 ID 规则。
- `dealer.ts`：兼容原 `findSequence` 接口，分发默认策略，可选只读开发观察者。
- `reducer.ts`：只更换补牌调用和传递已计算的 combo/dryMoves；规则顺序与计分不改。模拟通过注入发牌函数复用同一个 reducer，不另写得分或 Combo 规则。
- `dealer-memory.ts`：可缺省、严格校验、有界的策略历史。新字段 `state.dealer` 保存两个策略计数与最近六家族；旧存档没有该字段时从无历史开始，未知/损坏历史单独丢弃，保留正常棋局。schema、规则、方块池版本及最高分键不变。

已有手牌不重发，已保存 RNG 不重置；未来补牌采用新策略、每组固定消耗 13 次 RNG，故不保证新旧策略未来手牌相同。新版本内部同状态/种子/历史可完全重放，页面刷新、暂停与后台不推进随机流或计数。策略检查点回退不要求清除存档；旧版可忽略新增历史，但未来发牌恢复旧策略。

新增搜索/发牌测试后全量 136 单元通过，包括候选见证重放、四候选硬预算、保留自然失败、策略连续上限、重复形状、可选历史降级与一次原子补牌。静态材质、预览、输入、计分、现有消除、音频及许可证文件保持基线内容。
